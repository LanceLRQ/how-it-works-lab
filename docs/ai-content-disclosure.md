# AI 创作与内容声明

## 创作方式与资料来源

本项目所有教程内容均由 AI 创作，基于公开文档和论文进行资料整理、解释、推导说明与教学化改写，包括配套示例和交互实验中的教学说明。

引用的论文、文档原文、插图、数据和第三方代码仍属于各自原作者或权利人；本声明不将这些材料称为 AI 原创，也不改变其许可。公开可访问不等于可以无条件复制或再分发。

资料来源应在相应章节或参考资料中标明。资料被引用并不代表原作者认可本项目的解释；未标注核验记录的内容，不应被理解为已经逐项人工审核、专家审阅或学术同行评议。

## 准确性与使用范围

**我们不保证所有内容 100% 准确，也不保证其完整性、时效性或适用于特定用途。** AI 可能误解原始资料、生成不准确的引用、遗漏条件，或在公式、代码、翻译和结论之间产生不一致。

为了便于学习，课程可能采用简化模型、缩小的数据规模、示意动画或特定输入。演示结果只说明对应实现和实验条件下的现象，不能直接推广为完整生产系统的行为。教学算法和示例代码不构成经过生产级验证的实现。

请以原始论文、官方文档和现行标准为核对依据，并关注版本、适用条件和后续勘误。用于实际工程、研究或其他重要决策前，应独立验证。通过测试只说明所覆盖的情形通过，不等于课程全部事实与解释都正确。

## 纠错方式

欢迎通过[项目 Issues](https://github.com/LanceLRQ/how-it-works-lab/issues)反馈。请尽量提供：

- 课程、章节或页面地址，以及需要核对的原文。
- 认为有误的原因和可核对的论文、官方文档、版本或章节位置。
- 涉及代码或实验时，提供最小输入、复现步骤、实际结果和预期结果。

维护者应根据证据核查、修订，并在影响既有结论时说明更正范围。不要在反馈中提交密钥、账号凭据或个人学习数据。

## 给课程作者和开发 agent

- 对关键公式、数字、历史事实和算法结论保留可定位的来源；不能确认的内容应明确标注或暂缓发布，不编造 DOI、作者、引文或实验结果。
- 区分原文引用、转述、教学简化和项目自己的实验观察；说明简化省略了什么。
- 正确性检查应尽量使用独立依据，例如标准测试向量、已知答案或不同实现的交叉比对，不能仅用同一段生成逻辑给自己作证。
- 在课程 README 和面向读者的关于页或页脚提供本声明或等价说明；不得宣称未实际发生的人工审校。
- AI 创作声明不能代替来源核验、测试、版权署名或错误修复。
